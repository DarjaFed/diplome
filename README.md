# Дипломный проект: Автоматизация тестирования веб-приложения покупки тура
## Описание проекта

В рамках дипломного проекта реализовано автоматизированное тестирование веб-приложения покупки туристического тура.

### Приложение поддерживает два способа оплаты:

* покупка тура по банковской карте;
* покупка тура в кредит.
  Автоматизированные тесты проверяют корректность работы пользовательского интерфейса, обработку платёжных операций и сохранение данных в базе данных.
#### Цель проекта — автоматизация проверки пользовательских сценариев, валидации формы оплаты и корректности записи данных в базу данных.

### Используемые технологии
* Java 17
* Gradle
* JUnit 5
* Selenide
* Docker
* MySQL
* PostgreSQL
* Allure Report
* Lombok

#### Основные пакеты
tests — тестовые классы;
pages — Page Object страницы оплаты;
data — генерация тестовых данных;
utils — вспомогательные методы;
docker-compose.yml — запуск контейнеров.
Предварительные требования

##### Для запуска проекта должны быть установлены:

* Docker Desktop;
* Java 17;
* Gradle;
* Git.
  Проверка версий:

java -version
docker -v
git --version
### Запуск проекта

#### 1. Запуск контейнеров

docker-compose up -d

Будут запущены:

- MySQL
- PostgreSQL
- Gate Simulator

##### Команда запускает:

* MySQL;
* PostgreSQL;
* Gate Simulator.

Проверить состояние контейнеров:

docker ps

### 2. Запуск SUT

Для MySQL:

java -Dspring.datasource.url=jdbc:mysql://localhost:3306/app \
-Dspring.datasource.username=app \
-Dspring.datasource.password=pass \
-Dspring.credit-gate.url=http://localhost:9999/credit \
-Dspring.payment-gate.url=http://localhost:9999/payment \
-jar aqa-shop.jar

Для PostgreSQL:
java -Dspring.datasource.url=jdbc:postgresql://localhost:5432/app \
-Dspring.datasource.username=app \
-Dspring.datasource.password=pass \
-Dspring.credit-gate.url=http://localhost:9999/credit \
-Dspring.payment-gate.url=http://localhost:9999/payment \
-jar aqa-shop.jar
После запуска приложение должно быть доступно по адресу:

http://localhost:8080
### 3. Запуск автотестов
   ./gradlew clean test

### 4. Формирование отчёта Allure
   ./gradlew allureServe

После выполнения команды отчёт откроется в браузере автоматически.

#### Конфигурация приложения

Файл application.properties:

spring.datasource.url=jdbc:mysql://localhost:3306/app
spring.datasource.username=app
spring.datasource.password=pass

spring.credit-gate.url=http://localhost:9999/credit
spring.payment-gate.url=http://localhost:9999/payment

Файл gradle.properties:

org.gradle.jvmargs=-Dfile.encoding=UTF-8

### Реализованные тестовые сценарии
#### Покупка по карте

Проверяются:

* успешная оплата;
* отклонённая карта;
* пустые обязательные поля;
* некорректный номер карты;
* некорректный месяц;
* некорректный год;
* истёкший срок действия карты;
* некорректный CVV;
* некорректное имя владельца.

Всего: 18 тестов.

#### Покупка в кредит

Проверяются аналогичные сценарии для функционала оформления кредита.

Всего: 21 тест.

### Проверка базы данных

#### Реализованы проверки:

* запись статуса APPROVED;
* запись статуса DECLINED;
* корректность сохранения данных после выполнения операций оплаты и кредита.

#### Что проверяют автотесты

Автотесты проверяют:

1. корректность работы формы оплаты;
2. корректность работы формы кредита;
3. валидацию пользовательских данных;
4. обработку успешных платежей;
5. обработку отклонённых платежей;
6. корректность записи данных в базу данных.

### Отчётность

В проекте используется Allure Report.

Для формирования отчёта:

./gradlew allureServe

#### Отчёт содержит:

* результаты выполнения тестов;
* статистику прохождения;
* сведения об ошибках;
* приложенные скриншоты при падении тестов.

#### Завершение работы

##### Остановить контейнеры:

docker-compose down

##### Удалить контейнеры и тома:

docker-compose down -v
